# SMG · Sudo Ma Godo

Web app personale (PWA) che ogni giorno propone una seduta diversa per bici da strada, MTB/gravel, rulli (MyWhoosh) e corsa, adattata al check-in del mattino (sensazioni, HRV, FC a riposo, sonno) e al meteo.

- Semaforo di prontezza, massimo due sedute dure a settimana, una settimana di scarico ogni quattro.
- Collegamento facoltativo a Intervals.icu: legge i dati di benessere dal Garmin e invia la seduta a Garmin Connect (Fenix, Edge) e MyWhoosh.
- Meteo da Open-Meteo.

I dati restano solo nel telefono (memoria del browser): questo repository contiene solo il codice.
